# Mode prompt templates

Fill the placeholders, keep the camera / light / material language, then submit.
`{{subject}}` = the product as the user described it, `{{brand}}` = brand or palette
hint (may be empty), `{{surface}}` = the placement or surface, `{{extras}}` = user
specifics. Delete a line only when it contradicts the request.

Shared quality tail (append to every mode):

> photographed, not rendered; true-to-life material texture; clean edges, no halos;
> accurate label text, no invented words; natural depth of field; no watermark, no
> added logos, no duplicated product.

## product_shot

> backdrop, soft large-source key light from upper left with a gentle fill and a
> subtle contact shadow, 85mm look, f/8 sharpness across the label, matte-to-gloss
> material fidelity, generous negative space, {{extras}}.

## restyle

> Keep the existing composition, crop, product and label EXACTLY unchanged. Change
> only the aesthetic: {{surface}} mood, {{brand}} palette, matching light direction
> and grain. No new objects, no relighting of the product itself, {{extras}}.

## Variant axes (vary one at a time)

1. camera: eye level / 30-degree / overhead
2. light: soft key / hard sun / moody rim / window daylight
3. surface: seamless / textured stone / linen / wood / glass
4. palette: brand-true / monochrome / complementary accent

Never vary two axes in one variant; the set stops reading as one campaign.
